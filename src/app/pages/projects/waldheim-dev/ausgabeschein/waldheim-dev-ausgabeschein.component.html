Netbox Ausgabeschein Der Ausgabeschein-Generator dient als Verbindungsstück zu einem Netbox-System. Hierbei wird die Suche von Netbox angesteuert, um eine Suche nach Geräten zu ermöglichen. Aus den Ergebnissen können dann Unterschiedliche Scheine erzeugt werden, welche die IT für eine Saubere Protokollierung für die Verteilung von Geräten benötigt. Dadurch lassen sich der Ausgang, die Rückgabe oder die Überlassung von Hardware vollständig und korrekt nach bewährten Standards in Deutschland dokumentieren.
  • Hosting auf beliebigen Apache / ngnx
  • Automatisches Versionieren und Bereitstellung von Versionen
  • Gestaltung einer modernen Lösung basierend auf Angular
  • Erstellen eines eigenen Themes für Material Design (Angular Standard mit eigenen Farben)
  • Optimierung bis zum Smartphone
  • Anbindung der Such-Schnittstelle von Netbox
  • 28 Sprachen werden unterstützt
  • JSON-Konfiguration und Konfig-Generator
  • OpenSource Project zur Einsicht in den Code
