Homepage Die Webseite des Musikvereins Obermeitingen wurde komplett neu entwickelt basierend auf neuen Technologien und zur optimierung der Pflege von unterschiedlichsten Personen. Dabei wird der Fokus darauf gesetzt, dass die Webseite Google-Optimiert ist und zudem drei Schwerpunkte abdeckt, wie z.B. das Werben von neuen Mitgliedern, die ankündigung und Verbreitung von neuen Events und die Terminplanung und Materialplatform für bestehende Mitglieder.
  • Hosting auf Hetzner
  • Automatisches Versionieren und Deployen
  • Gestaltung einer modernen Lösung basierend auf WordPress / React / JSX / Web-Components
  • Erstellen eines eigenen Themes für die Webseite
  • Optimierung bis zum Smartphone
  • Implementierung eines automatischen Deploys via SSH für die Plugins
  • Implementierung von PHP basierten Backend
  • Entwicklung von eigenen Plugins für WordPress um keine Probleme mit Updates zu erhalten.
