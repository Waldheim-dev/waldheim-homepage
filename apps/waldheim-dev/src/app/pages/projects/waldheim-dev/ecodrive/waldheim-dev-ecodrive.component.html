Ecodrive ist eine Software zur Nutzungsermittlung. Dabei werden Daten von Fahrzeugen und deren laufenden Kosten erfasst. Dadurch können Effizient und Kosten überblickt und gesammelt werden. Für Firmen gibt es mit einem Upgrade auch die Möglichkeit direkt ein Fahrtenbuch aus den Daten zu generieren.
Docker Angular C# Firebase OAuth2 Angular-Material Gitlab-CI CleanCode Jest Cypress SonarQube REST Jira Webstorm Visual Studio Code Typescript Stripe Apexcharts Code-Security

  • Implementieren von Kostenabrechnung
